 Petite application pédagogique pour indiquer à un groupe ou à un élève comment il pourra utilsier l'IA durant la séance. L'application simule un "bandit manchot" avec temporalité de l'usage, contrainte et posture de l'IA. 
 A l'ouverture, on peut conserver ou supprimer les propositions de chaque rouleau et en ajouter pour personnaliser.
